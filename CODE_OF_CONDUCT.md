# Code of conduct

## The short version

Be decent to each other. Assume the person you are talking to is trying to
help learners, because that is why they are here.

## Not acceptable

Harassment, insults, or personal attacks. Discriminatory language about
nationality, ethnicity, religion, gender, sexuality, disability or age —
which would be especially out of place in a project for language learners,
most of whom are migrants. Publishing anyone's private information.
Deliberately derailing discussions.

## Scope

Issues, pull requests, discussions, and anywhere someone is representing the
project.

## Enforcement

Report problems to the maintainer through a GitHub issue or directly. Reports
are handled privately. Consequences range from a warning to a permanent ban,
depending on severity.

Adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/),
kept short deliberately so that it gets read.
