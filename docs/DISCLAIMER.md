## Copyright

### What is not protected

An examination's **format** is a set of published factual specifications — five
parts in the reading module, 30 items, 65 minutes, 100 points, a 60 % pass mark.
Facts and formats are not copyrightable subject matter. This project follows
that format precisely, which is exactly what makes it useful for practice.

### What is protected

The **content** of published examination papers — the actual texts, questions,
distractors and audio recordings — is protected by copyright, and the model sets
and past papers published by examination bodies and by commercial publishers
(Cornelsen, Klett, Hueber and others) are their property.

### What this project therefore does

Every reading text, listening script, question, distractor, answer key,
rationale, writing task, speaking card and glossary entry here is **written from
scratch**. Nothing is copied, transcribed, paraphrased from, or machine-derived
from any official or commercial material.

No third-party PDFs, audio files, images or fonts from examination bodies or
publishers are vendored into this repository. Official materials are **linked**
in the README so learners can obtain them from the source, for free, from the
people who made them.

`docs/AUTHORING.md` states this as rule number one, and every pull request that
touches `content/` must affirm it via the checklist in the PR template.
